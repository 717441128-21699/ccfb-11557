# 瓷砖纹理工坊 · Tile Texture Studio

浏览器打开即用的陶瓷釉面瓷砖**四方连续纹理生产工具**。美工把拍好的样片照片导入，
经过透视/光照校正、基于样本的纹理合成、PBR 贴图烘焙，直接产出可平铺的
颜色 / 法线 / 粗糙度 / 高光贴图，并能在三维墙地面实时预览、同款多色号批量导出
PNG 与 KTX2。纯前端 TypeScript 实现，照片与贴图不出本机。

## 五个工作页

| # | 页面 | 能力 |
|---|------|------|
| 1 | 样片导入与校正 | 照片导入、四角拖拽透视校正、大半径高斯照度场匀光 |
| 2 | 去接缝合成 | 环形 Image Quilting 任意尺寸四方连续合成、九宫格目检、接缝统计检验 |
| 3 | 贴图烘焙 | 颜色图推导法线 / 粗糙度 / 高光 / 高度图，参数防抖实时重烘焙 |
| 4 | 铺贴预览 | Three.js PBR 实时铺墙铺地、灯光/曝光/清漆调节、轨道旋转缩放 |
| 5 | 批量导出 | 同款多色号（Lab 迁移 / HSL 调整）批量处理、PNG + KTX2 导出、参数预设 |

## 核心算法

### 四方连续纹理合成（`src/core/synthesis.ts`）
环形（toroidal）Image Quilting：

1. 输出画布是环面，块坐标越界自动回绕，四边天然连续；
2. 随机样本块先铺满环面，保证所有重叠区都有合法邻居；
3. 蛇形扫描两遍，重叠区按 SSD 选候选块，动态规划 Min-Cut 切缝，
   第二遍重切回绕接缝；
4. 环形双线性重采样到目标尺寸（缩放不引入接缝）；
5. 环面条带样条混合（`toroidalBlend`），在回绕边两侧窄条带内把像素
   平滑拉到共同中点，**接缝处两侧取同一值（零色差），内部像素原样保留**。

### 接缝统计检验（`src/core/seamstats.ts`）
工程目标是"接缝与内部**统计上无显著区别**"，这是等效性问题而非差异性问题，
因此采用 **TOST 双单侧等效性检验**：

- 接缝样本取左右、上下回绕边的相邻像素对；内部样本取边界安全区内的相邻对，
  绝不触碰回绕边（避免基准污染）；
- 等效界值 `margin = max(1.5, 内部色差均值, 0.35·内部色差标准差)`；
- 两个单侧 t 检验同时被拒绝（p < 0.05）判定等效；近完美零接缝直接通过；
- 同时报告 Welch 差异性 p 值与 Cohen's d 效应量。

负对照（强梯度非平铺图）必不通过、正对照（周期纹理、零接缝）必通过，
判别力由 `tests/pipeline.test.ts` 覆盖。

### PBR 烘焙（`src/core/pbr.ts`）
高度图取亮度并环形高斯去噪；法线用**环形 Sobel** 求梯度并归一化；
粗糙度、高光同样全程环形边界处理，因此四张 PBR 图与颜色图保持一致的可平铺性。

### 性能
大半径模糊用**积分图盒式模糊 ×3 逼近高斯**，复杂度 O(像素)、与半径无关。
1024×1024 全流程（校正 + 合成 + PBR 烘焙 + 检验）在普通开发机约 0.6 秒，
2048 约 2.3 秒；重活全部在 Web Worker 中执行，进度走高通道增量更新，不卡 UI。

## 导出格式

- **PNG**：每色号 4 张（color / normal / roughness / specular）；
- **KTX2**：`VK_FORMAT_R8G8B8A8_UNORM` 未压缩，带完整 mipmap 链与标准 DFD，
  法线/粗糙度等线性数据标记线性传输函数。可被 three.js 等直接加载；
  如需 Basis/UASTC GPU 压缩，可在此文件基础上用 toktx / basisu 再压缩。

## 开发

```bash
npm install
npm run dev        # 本地开发
npm run typecheck  # 类型检查
npm test           # 28 项算法端到端测试（Node，esbuild 打包后运行）
npm run build      # 生产构建
```

浏览器冒烟测试（需要本机有 Chromium，走完整真实用户流程）：

```bash
npm run dev -- --port 5199
CHROME_PATH=/path/to/chrome.exe BASE_URL=http://localhost:5199 node tests/smoke.mjs
```

## 技术栈

Vite + TypeScript（严格模式）、Three.js（PBR 预览）、ktx-parse（KTX2 容器）、
Web Worker。无后端、无外部图像处理库，所有算法在本仓库 `src/core` 自研实现。
